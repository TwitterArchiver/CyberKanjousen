日常被父母甩锅（114514/1）

環状線上大学买了新电脑后，就把之前的旧电脑给家里人用。去年离手前电脑还很干净，今天打开一看，电脑已经面目全非，里面全是国产流氓软件，每隔几秒还要弹个傻逼广告恶心你。

母亲指着满是广告的屏幕对環状線说：「你看这都是你乱搞的，俺们一点都没动。」

*中国粗口 *又把锅甩给環状線是吧？那環状線问你，去年这个电脑还是 Windows 11，现在怎么变成 Windows 10 了？难不成 Windows 它会自己降级？

環状線可是清楚记得，去年把旧电脑交给家里的时候，母亲还问環状線「要重装系统，有没有什么要留下的文件」，今天怎么又说「一点都没动」？相反，你们重装系统后，環状線至今都没有再动过那个电脑，「一点都没动」的应该是環状線吧！

你们嫌環状線「乱搞」，但你们把电脑蹂躪成这副鬼样子，任凭国产流氓软件对那个旧电脑实施轮奸，还把电脑的触控板驱动搞坏了，你们哪里来的资格说環状線「乱搞」呢？
