时隔 5 年半重逢安卓（虽然只是一台用于搭建软路由的二手 Pixel 6）
我虽然更喜欢 iOS 的 UI 设计，但不得不承认，原生安卓的设计师非常有品位。和争相对苹果东施效颦、一看就是土包子设计出来的的国产 UI 不同，原生安卓不需要多余的装饰证明自己好看，也不需要多余的功能证明自己能干……后面的语言我想不出来了，总之原生安卓的 UI 就是好
不过推特的安卓客户端说实话不如苹果的好看，而且似乎不能修改主题配色；Telegram 安卓客户端的 UI 实在一言难尽，像是安卓和 iOS 的缝合产物
这台 Pixel 6 搭载的是 Andriod 14，据 Grok 称搭载 Android 14 的 Pixel 的续航比 Android 13 好，所以我就没给系统降级。Android 14 以上的系统禁止通过 APK 安装 targetSdkVersion 小于等于 22 的应用（连从 QQ 官网上下载的 QQ APK 都无法直接安装😅），所以手机上用来配置路由的 NegoBox 是通过 ADB 安装的
短暂体验下来，这台 Pixel 6 相当流畅，在作为软路由之余完全可以当我的副机使用（虽然实际上我要一台副机没什么用）。下拉菜单偶尔会卡 bug ，会在下拉菜单里卡住不动，只有熄屏再解锁手机才能退出下拉菜单，不过作为软路由而言的话，问题倒也不大
还可以用来玩明日方舟，流畅度一般
（国服明日方舟安装也需要 ADB 🫠）
